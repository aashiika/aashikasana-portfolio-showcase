# Aashika's Digital Canvas

Create a **professional, interactive, modern Student Portfolio Website** for **Aashika Sana.A**, a **B.Sc. Computer Science with Data Analytics student**.

### 1. Technology

Build the entire website using only:

* HTML5
* CSS3
* Vanilla JavaScript

Do **not** use React, Angular, or other frameworks.

The code must be clean, well-organized, responsive, and easy for a beginner to edit later.

### 2. Theme & Design

Use a **light blue / sky blue professional theme**.

Design requirements:

* Modern student portfolio appearance
* Clean white and light-blue backgrounds
* Blue gradient accents
* Soft shadows
* Rounded cards
* Smooth hover effects
* Beautiful animations
* Professional typography
* Interactive buttons
* Smooth scrolling
* Responsive design for mobile, tablet, and desktop
